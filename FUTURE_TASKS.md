## Приоритет (следующие итерации)

### P1. Слой «Проявленные цели» (замена раздела «Задачи»)
- **Статус**: реализован 07.08.2026 — бэкенд (`GOALS_PROMPT` в ai.py, все эндпоинты в goals.py, таблица goals) и фронт (goalsSection, навигация: «Задачи» скрыта, «Цели» добавлена)
- Куратор выводит 3–5 «проявленных целей» из суммарных заметок, без чекбоксов/дат/статусов. Цель = мягкая обёртка над thread-ом с именем и весом.
- **Осталось**: интеграционные тесты на /api/goals (в `test_feat.py` не покрыты), live-прогон на проде (user `mdnow`).
- Варианты А (список целей с цитатами-источниками) и Б (цель-диалог: куратор раскрывает цитаты + вопрос) — одобрены пользователем.
- Референс механик: Mem AI (Discovery Engine, Heads Up, Actionable Chat, Collections).
- Зависит от: thread_name (P2), эмбеддингов/поиска по смыслу (P2), Heads Up (в работе 07.08).

### P2. Сохранять thread_name у нитей
- **Источник**: аудит 07.08 (AI Connections «работает, но грубо»)
- Сейчас `thread_suggest` возвращает `thread_name`, но он не сохраняется в БД; нити — плоский список UUID без имён.
- Нужно: колонка thread_name у thread-ов (или в notes), отображение имён в списке нитей, эволюция нитей (переименование/уточнение по мере роста).

### P2. Actionable Chat (чаты-действия)
- **Источник**: аудит 07.08 (Mem Chat стал Actionable — «собери мне из заметок за месяц дорожную карту» → создаёт/обновляет артефакты)
- Сейчас куратор отвечает текстом, единственное действие — сохранение мысли.
- Нужно: команды вида «собери карту/отчёт по теме X» → куратор создаёт/обновляет заметку/раздел/цель.
- Важно: в рамках «безопасный чат» (см. P3) — только по явной просьбе.

### P3. Семантический поиск по заметкам (Discovery Engine)
- **Источник**: аудит 07.08 (п.1)
- **Статус**: бэкенд готов частично — таблица `note_embeddings`, генерация при создании/изменении заметки, `/api/notes/related` (Heads Up). **Не сделано**: подключение семантического поиска в UI — поиск по-прежнему LIKE через `/api/chat/search`.
- Эмбеддинги подтверждены: `nvidia/nemotron-3-embed-1b:free` (200 OK, dim 2048, семантика работает), Neon PostgreSQL 18.4 поддерживает pgvector.
