# Curator v3 — Будущие задачи (бэклог)

Создан: 07.08.2026. Обновляется по мере появления задач.
Правило: задачи сюда попадают, когда решено «сохранить на потом», и выполняются по приоритету сверху вниз.

**Бэклог с ID — единый источник правды по задачам.** Каждая просьба → строка `T-0xx` здесь ДО начала работы. Формат:

```
T-0xx. Краткое название
- **Статус**: `в работе` | `сделано, ждёт подтверждения` | `подтверждено`
- **Как проверить**: что именно смотреть, какой результат ожидается
- Ссылки: сессия / ADR / коммит (по необходимости)
```

Статус меняется только так: `в работе` → `сделано, ждёт подтверждения` (после деплоя и проверок) → `подтверждено` (после явного слова Marina «работает»). В архив «выполнено» — только после `подтверждено`. Повторная просьба — сначала поиск по ID и статус, а не переделка вслепую.

### T-003. Интеграция Куратора с Mem AI (mem.ai) — обмен заметками
- **Источник**: задача из «Карты дня» (19.08.2026), «Мой Мем AI» = Mem (mem.ai), независимый AI-ноутбук
- **Статус**: `сделано, ждёт подтверждения` (код задеплоен, live-проверки: поиск/импорт/экспорт + чтение в диалоге + копирование по просьбе)
- **Как проверить**: с VPN: `GET /api/mem/search?q=...` возвращает заметки из Mem (api.mem.ai/v2/notes/search); импорт — заметка Mem → заметка Куратора с тегом `mem`; экспорт — заметка Куратора → `POST /v2/notes` в Mem (в коллекцию/без). В диалоге: «найди в меме цитату про X» → куратор отвечает реальными цитатами из Mem; «скопируй из мем цитату про X себе в заметки» → заметка с тегом `mem` создаётся в Кураторе. API-ключ `MEM_API_KEY` в `.env` (не коммитится).
- **Ограничение**: api.mem.ai геоблокирован из РФ — интеграция работает только при включённом VPN (запись в VPN_SERVICES.md). На проде нужен `MEM_API_KEY` в env Render (пока не добавлен — mem-эндпоинты вернут 400).
- Ссылки: ADR-0018 (схема связи), сессии 19.08 (SESSION_JOURNAL), коммиты `16d790b` (API обмен) + `8da4dc2` (диалог/копирование)

### T-004. Синк всего корпуса заметок в Куратора (паттерн-детекция прошлых мыслей)
- **Источник**: Марина (20.08.2026): «хочу чтобы куратор вылавливал паттерны и контексты обо мне и брал информацию из всех моих заметок — например, я сейчас думаю про перегрузку НС, а куратор видит, что я это уже думала в марте и мае»
- **Статус**: `сделано, ждёт подтверждения`
- **Как проверить**: в диалоге с куратором поднять тему из прошлых заметок («моя нервная система перегружена») → куратор отвечает блоком «ТЫ УЖЕ ДУМАЛА ОБ ЭТОМ РАНЬШЕ» с датами. На проде работает через tsvector (ключевые слова). Локально — semantic (fastembed, dist).
- **Результат**: 2811/2811 файлов Obsidian в базе, tsvector на всех записях. Поиск на проде: `plainto_tsquery('russian', ...)` через GIN-индекс. Smoke: «налог на выход» rank 0.9999, «нервная система» rank 1.0, «деньги» rank 0.75. Commits: `da85adc` (tsvector), `e46249e` (pool-reset).
- **Ограничение**: semantic-search (понимание смысла без точных слов) доступен только локально. На проде — полнотекстовый поиск по ключевым словам. Для semantic на проде нужен внешний embedding-API или платный хостинг.
- Ссылки: ADR-0019, `da85adc`, сессии 20–21.08 + 25.08 (SESSION_JOURNAL)

### P3. Семантический поиск по заметкам (Discovery Engine)
