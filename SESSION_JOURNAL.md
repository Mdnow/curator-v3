## Сессия: 2026-08-16 (добавка 7) — «Автор» → «Марина» в саммари заметок

**Тема:** задача из «Карты дня» — персонализация: AI-саммари заметок подписывало владелицу безличным «Автор»/«Авторка», что режет слух в личном приложении.

**Диагностика:** в коде слова «Автор» нет — подпись генерировал AI внутри `ai_summary`. Проверка прод-БД: 82 заметки mdnow с «Автор», 0 с «Марина»; все случаи — про владелицу (чужих «автор книги/цитаты» — 0, категория «Цитаты» не затронута).

**Что сделано:**
- **Промпты** (`backend/ai.py`): `ANALYZE_NOTE_PROMPT` — правило «владелицу заметки называй по имени — Марина, никогда не используй „Автор"/„Авторка"»; `CHAT_SYSTEM` — правило 1.1 «пользователь — Марина, не называй её „Автор"/„пользователь"». Новые заметки сразу генерируют «Марина …».
- **Существующие данные** (Neon): пакетный `regexp_replace` по `ai_summary` (`\yАвторка\y|\yАвтор\y|...` → «Марина») — 80 строк; 2 случая с падежом («заметками автора» → «заметками Марины», «радуют автора» → «радуют Марину») — точечно по id 345/436. Итог: «Автор» = 0, «Марина» = 80+2.

**Проверено:** live-вызов `analyze_note` на новом промпте — summary/theses пишут «Марина …» (не «Автор»); SQL-проверка после правки — «Автор» в ai_summary отсутствует; ruff/py_compile OK.

## Сессия: 2026-08-16 (добавка 2) — кнопка «сохранить» при выделении текста во всём Кураторе

**Тема:** задача из «Карты дня» (после шага 10) — единый capture-флоу: выделил текст в любом экране → появилась кнопка «сохранить» → текст стал новой заметкой. Плюс закрыт открытый баг «клик „сохранить" не срабатывает».

**Диагноз бага (шаг 10):**
- Тулбар выделения был ограничен только чатом: `if (!chatEl.contains(range.commonAncestorContainer))` в `initSelectionToolbar` — в заметках, снах, целях, тиктоке и поповерах кнопки не было вовсе.
- Конфликт позиционирования на мобильном: JS ставил инлайн `top`, а mobile.css — `bottom: calc(...)`. Инлайн `top` перекрывал CSS, но при `bottom` в стиле элемент мог растягиваться/смещаться — клик «мимо кнопки».
- z-index тулбара (999) был ниже модалок (1000) — при выделении внутри поповера кнопка пряталась под модалку.

**Что сделано (frontend, бэкенд не менялся):**
- `frontend/js/app.js` `initSelectionToolbar`: убрано ограничение чатом — тулбар работает в любом месте приложения. Добавлены `selectionchange` (дебаунс 250мс) и `touchend` — работает на мобильных; `touchstart` скрывает по тапу вне тулбара; `scroll` (capture) скрывает при прокрутке.
