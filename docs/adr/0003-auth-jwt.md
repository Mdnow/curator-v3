# ADR-0003 — Аутентификация: пароль (PBKDF2) + JWT

- **Дата:** 06.08.2026
- **Статус:** accepted

## Контекст

Приложение single-user (`mdnow`), но прод публично доступен на Railway.
Нужна защита от постороннего доступа к личным данным.

## Решение

- Пароль хешируется PBKDF2 (не хранится в открытом виде).
- После логина — JWT (HS256, срок 720 ч) в `backend/auth.py`.
- Все роуты принимают `user_id` из JWT через `get_current_user` (Depends) —
  ни один запрос не идёт мимо auth.

## Альтернативы

- Внешний провайдер OAuth — избыточно для single-user.
- Сессии на куках — сложнее в API-виде, отдано предпочтение JWT.

## Последствия

- Без знания пароля прод недоступен.
- Секрет JWT — `CURATOR_SECRET` в .env; утечка секрета = перевыпуск токенов.
- Долгий срок токена (720 ч) удобен, но если пароль скомпрометирован —
  перелогин.
