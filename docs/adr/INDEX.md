# Реестр решений (ADR) — Curator v3

Здесь живут архитектурные решения проекта. Правила:

- **Новое решение** → новый файл `000N-*.md` + строка в этой таблице.
- **Старые ADR не редактируются** — если решение устарело, статус меняется на
  `superseded` и указывается заменитель. История решений честная.
- В журналах и спеках ссылайся на номер (ADR-0001), не дублируй содержание.
- Перед изменением кода читай эту таблицу — не противоречь принятым решениям.
