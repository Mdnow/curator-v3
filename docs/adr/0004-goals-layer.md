# ADR-0004 — Раздел «Задачи» → слой «проявленные цели»

- **Дата:** 07.08.2026
- **Статус:** accepted

## Контекст

Философия продукта: самоценность не равна продуктивности (DECOUPLING).
Раздел «Задачи» с чекбоксами и датами давит — противоречит принципу
«зеркало, а не планировщик». Пользователь: «в чём я варюсь в каждом дне» —
куратор должен показывать паттерны, а не долги.

## Решение

Раздел «Задачи» в UI скрывается, вместо него — слой **«проявленные цели»**:
куратор выводит 2-5 целей из повторяющихся заметок с дословными цитатами
(≥2 цитат из разных заметок). Без чекбоксов, дат и статусов.
Бэкенд `/api/tasks` остаётся (не удаляем, совместимость). Спека: `GOALS_SPEC.md`.

## Альтернативы

- Оставить «Задачи» как есть — отклонено: противоречит принципу DECOUPLING.
- Полностью удалить бэкенд задач — отклонено: лишняя работа, ломает данные.

## Последствия

- UI становится целостным: вход — записи, выход — отражение паттернов.
- Цель — это паттерн с цитатами, а не задача; генерируется по кнопке,
  не чаще раза в день (AI-вызов).
- `evidence` хранит копии цитат — при редактировании заметки цитата не
  обновляется автоматически (перегенерация решает).
