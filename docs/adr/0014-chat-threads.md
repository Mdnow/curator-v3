# ADR-0014 — Ветки чата: диалог = тема с названием (модель ChatGPT/Claude)

- **Дата:** 17.08.2026
- **Статус:** accepted

## Контекст

Кнопки «обсудить» (заметка, тема дня, цель) разбросаны по приложению, но их
диалоги нигде не сохраняются, а архив главного чата — «полный бардак»:
сессия = кусок времени (новая каждые 2 часа), заголовок — обрезанное первое
сообщение, темы разорваны между сессиями. Пользователь хочет модель как в
ChatGPT/Claude: каждый вход («обсудить», «новый диалог») создаёт отдельный
чат, диалог сохраняется в едином архиве с коротким названием по смыслу.

## Решение

**Ветка (thread) = тематический диалог.** Сообщения привязаны к ветке, у
ветки — название, генерируемое AI из первого сообщения.

**Модель данных**

- Таблица `chat_threads` (`id`, `user_id`, `title`, `created_at`,
  `updated_at`).
- `chat_history.thread_id` (nullable, `ON DELETE CASCADE`) — привязка
  сообщения к ветке. Старые `session_id` остаются в схеме, но не участвуют
  в новой логике.
- Миграция (`init_db`, идемпотентна): каждая группа `(user_id, session_id)`
  → одна ветка (заголовок из первого сообщения); «несохранённые» сообщения
  без сессии и проекта → ветка «старые сообщения». Ничего не теряется.

**API** (`chat.py`)

- `/api/ai/chat`: `ChatReq` получает `thread_id`. Если задан — продолжение
  ветки; если нет — создаётся новая ветка. `project_id` продолжает работать
  как диалог проекта (ADR-0013) — не затронут.
- Заголовок ветки генерируется фоном (`BackgroundTasks`) из первого
  сообщения через `generate_thread_title` (2-5 слов, бесплатная модель),
  по образцу `ai_title` у заметок (ADR-0006).
- `/chat/sessions*` заменены на `/chat/threads`, `/chat/threads/{id}`,
  `DELETE /chat/threads/{id}`; поиск возвращает `thread_id`.
- Бэкап экспортирует `thread_id` вместе с сообщениями.

**Фронтенд**

- `currentThreadId` вместо `currentSessionId`.
- Все «обсудить» (заметка, тема дня, цель, материал проекта, выделенный
  текст, Heads Up) → `newChat()` + автоотправка сформулированного вопроса
  в новой ветке.
- Шапка чата показывает название текущей ветки (или «куратор» для новой).
- Архив — единый хронологический список веток (по последней активности):
  название, дата, число сообщений, поиск.

## Альтернативы

- Оставить сессии по времени — отклонено: именно их хаос в архиве и хотел
  убрать пользователь.
- Перевести диалоги проектов на ветки тоже — отложено пользователем
  («ещё не тестировала на удобство»), проект-диалог остаётся как в ADR-0013.

## Последствия

- Каждый вход из «обсудить» создаёт отдельную ветку (даже повторно по той
  же заметке) — как в ChatGPT/Claude, название различает их в архиве.
- Один AI-вызов на ветку для заголовка (бесплатно, фоном, не блокирует
  ответ).
- `chat_threads` удаляются каскадно при удалении пользователя; `clear_all`
  чистит и ветки, и сообщения.
- Проектные диалоги не появляются в архиве веток (остаются внутри проекта).
