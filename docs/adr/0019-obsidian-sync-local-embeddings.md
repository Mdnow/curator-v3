# ADR-0019: Синк корпуса заметок Obsidian в Куратора + локальный семантический поиск

Дата: 21.08.2026
Статус: accepted

## Контекст

T-004: Марина хочет, чтобы куратор «вылавливал паттерны и контексты» — видел,
что мысль уже думалась раньше («я думаю про перегрузку НС, а куратор видит,
что я это писала в марте и мае»). Для этого нужен весь корпус её заметок
в базе с эмбеддингами.

Ограничения, которые определили решение:

1. **OpenRouter с российского VPN отвечает 403** на всё (даже без ключа) —
   облачные эмбеддинги из РФ недоступны.
2. **ZEN (api.opencode.ai) не имеет embed-моделей**, Groq тоже.
3. **Mem API (api.mem.ai)** отдаёт корпус (1412 заметок), но геоблокирован
   и требует VPN; сравнение показало, что **97% заметок Mem есть в локальном
   Obsidian** (`Dnlchk`, 2811 .md после исключения архивов) — Obsidian полнее
   и доступен без сети вообще.
4. **Render free = 512 MB RAM** — тяжёлая embed-модель на проде не поместится.
5. Компьютер Марины: 7.4 GB RAM — модель держать постоянно нельзя.

## Решение

**Источник синка — локальный Obsidian**, не Mem API. Однократный полный синк
запускается вручную с компьютера Марины; повторные запуски инкрементальные
(обрабатываются только новые файлы).

**Эмбеддинги — локальная модель fastembed**
(`sentence-transformers/paraphrase-multilingual-mpnet-base-v2`, dim 768,
L2-нормализация обязательна — у модели «сырая» норма ~2.0). Модель грузится
только в процессе синка (~2.7 GB RAM на время работы), на проде не используется.

**Хранение — прод-Neon**: таблицы `mem_notes` (контент зашифрован Fernet,
`mem_id = "obsidian:<полный путь>"`) + `mem_note_embeddings` (pgvector,
vector(768)). Объём ~25 MB из 512 MB free — некритично.

**Поиск:**

- Локально (полный): `mem_search_local()` — pgvector `<->` по запросу,
  эмбеддинг запроса той же локальной моделью.
- В чате (авто-режим): при каждом сообщении (без mem-интента и assign) —
  поиск по синкнутой базе, топ-4 с dist < 1.2 → блок «ТЫ УЖЕ ДУМАЛА ОБ ЭТОМ
  РАНЬШЕ» с датами в контекст куратора. Модель прогревается фоном при первом
  сообщении процесса; работает только там, где fastembed установлен (локально).
- На проде: авто-поиск отключается сам (fastembed не установлен) — поведение
  не ломается. Будущее направление — полнотекстовый поиск (tsvector) как
  бесплатная замена без памяти (см. «Последствия»).

**Даты заметок**: приоритет — дата из имени файла (русский/ISO формат) →
из текста (первые 1500 символов) → mtime файла (худший случай: дата
копирования, не написания).

## Последствия

- **+** Полный корпус (2811 заметок) доступен куратору без VPN, без лимитов
  search-API и без оплаты.
- **+** Синк не требует облаков: файлы + локальная модель + Neon.
- **−** Синк идёт только с компьютера Марины (файлы локальны); новый запуск
  при VPN-обрывах может требовать перезапуска.
- **−** Авто-поиск в чате работает только локально (модель не влезает в
  Render free). На проде нужен либо tsvector-поиск, либо дешёвый embedding-API.
- **−** Дубли файлов в Obsidian дают дубли в выдаче (чистка — будущая задача).
- **−** `MEM_API_KEY` по-прежнему не добавлен в env Render (см. T-003).
