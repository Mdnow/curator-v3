# ADR-0006 — Тезисы и саммари у заметок (ai_theses)

- **Дата:** 09.08.2026
- **Статус:** accepted

## Контекст

Пользователь: «в куратор в3 сделать саммари и чёткие тезисы». У заметок уже был
`ai_summary` (одно предложение), но не было тезисов. Импорт из tiktok-watcher
слал `ai_summary = content[:400]` — сырой срез, а не настоящую суть.

## Решение

- Колонка `ai_theses` (JSON-массив) у заметок + миграция в `init_db()`.
- `ANALYZE_NOTE_PROMPT` генерирует `theses` (2-4 чётких тезиса) для **любой**
  заметки (не только tiktok).
- `/api/notes/import` принимает `ai_theses`; watcher шлёт суть видео как
  `ai_summary` и тезисы как `ai_theses`.
- Блок тезисов в карточке заметки (фронт), `ai_theses` в бэкапе.

## Альтернативы

- Только для tiktok-заметок — отклонено: тезисы полезны для всех заметок,
  генерация дешёвая (одно поле в том же вызове).
- Хранить тезисы только в тексте заметки (как раньше у watcher) — отклонено:
  без отдельного поля фронт не мог показать их структурно.

## Последствия

- У каждой заметки появляется структурированный разбор: категория + саммари +
  тезисы + ключевые фразы.
- Старым заметкам тезисы появятся после «переанализа» (тратит AI-лимит).
- Модель `ImportNoteReq` обратно совместима (новое поле с дефолтом `[]`).
