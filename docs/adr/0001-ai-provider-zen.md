# ADR-0001 — AI-провайдер: OpenCode Zen + OpenRouter fallback

- **Дата:** 08.08.2026
- **Статус:** accepted

## Контекст

Куратор — AI-центричное приложение (категории, суммарии, чат, цели, инсайты).
До 08.08 всё работало через OpenRouter (ротация free-моделей), что давало
нестабильность: 429, суточные лимиты, исчезающие модели. Пользователь попросил
использовать бесплатные модели opencode (OpenCode Zen).

## Решение

Провайдер-слой в `backend/ai.py` (`PROVIDERS`):
- **Основной:** OpenCode Zen free-модели (big-pickle, deepseek-v4-flash-free,
  nemotron-3-ultra-free, mimo-v2.5-free + запасные).
- **Fallback:** OpenRouter free-модели (`OPENROUTER_MODELS`).
- **Embedding:** OpenRouter (`nvidia/nemotron-3-embed-1b:free`).
- Ротация через `call_ai_json()` — перебор провайдеров с JSON-валидацией.

## Альтернативы

- Только OpenRouter — отклонено: хрупкий (429, лимиты, исчезающие модели).
- freellmpool (пул 24 провайдеров) — отложено как запас (см. FUTURE_TASKS).
- Платные модели — отклонено: работаем только бесплатно.

## Последствия

- AI-слой перестал зависеть от одного провайдера.
- big-pickle в бесплатный период использует данные для улучшения модели —
  личные мысли уходят провайдеру (принято для личного использования).
- Интерфейсы вызывающих (`analyze_note`, `generate_goals` и др.) не менялись.
