# ADR-0018: Интеграция Куратора с Mem AI — обмен заметками

Дата: 19.08.2026
Статус: accepted

## Контекст

Задача из «Карты дня» (19.08.2026): связать Куратор v3 с «Моим Мемом AI».
Уточнено: «Мой Мем AI» — это **Mem (mem.ai)**, независимый AI-ноутбук
(«второй мозг»), не mem0 и не Mini Mem. У Mem есть публичный REST API
(`api.mem.ai/v2/notes`) с Bearer-авторизацией (`sk-mem-...`) — создание,
поиск, чтение, удаление заметок. Пользователь предоставил API-ключ.

Цель: Куратор — единая точка входа для личных проектов. Связь расширяет
контекст: заметки Mem доступны из Куратора, мысли Куратора — в Mem.

## Решение

Минимальный прототип обмена **одним типом сущностей — заметками (notes)**,
оба направления:

- **Импорт (Mem → Куратор)**: поиск по смыслу в Mem → выбрать заметку →
  создать заметку Куратора с тегом `mem`. Эмбеддинг делается фоново
  (без AI-анализа — не жечь лимит бесплатного AI, как в `/api/notes/import`).
- **Экспорт (Куратор → Mem)**: заметка Куратора → `POST /v2/notes` в Mem
  (первая строка content = заголовок Mem).

Код:

- `backend/mem_api.py` — HTTP-клиент Mem API (`mem_search`, `mem_read`,
  `mem_create`), httpx, таймаут 20с. При 401 — внятная ошибка «неверный ключ».
- `backend/routes/mem.py` — `GET /api/mem/search?q=`, `POST /api/mem/import`,
  `POST /api/mem/export`. Аутентификация — штатный JWT куратора.
- `MEM_API_KEY` в env (`.env` локально, не коммитится).

Ограничение: **api.mem.ai геоблокирован из РФ** (проверено: `000` без VPN,
`401` с VPN). Интеграция работает только при включённом VPN. Записано в
`VPN_SERVICES.md`.

## Последствия

- **+** Рабочий канал обмена заметками в обе стороны, проверен live (19.08).
- **−** Mem API требует VPN — без VPN роуты падают с 502 (честная ошибка
  через `RuntimeError` → HTTPException).
- **−** Пока нет UI: роуты вызываются напрямую (prototype). UI — следующий шаг.
- **−** Mem не хранит структуру Куратора (теги/проекты/даты) — при импорте
  тег `mem` добавляется, дата подставляется (переданная или сегодня).

## План дальнейшей интеграции

1. UI: вкладка/кнопка «Mem» — поиск, импорт, экспорт из интерфейса.
2. Семантика: при импорте сохранять `mem_id` заметки (маппинг Куратор↔Mem).
3. Автоматизация: «отчёт дня»/суммари → заметка в Mem по расписанию.
