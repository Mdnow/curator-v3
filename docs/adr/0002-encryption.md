# ADR-0002 — Шифрование данных пользователя (Fernet)

- **Дата:** 06.08.2026
- **Статус:** accepted

## Контекст

Куратор хранит личные мысли и сны. Продукт позиционируется как приватное
когнитивное зеркало. Данные лежат в облачной PostgreSQL (Neon) — нужна защита
на уровне приложения, а не только БД.

## Решение

Все чувствительные поля зашифрованы через Fernet (AES) в `backend/crypto.py`,
в БД хранятся в колонках `*_encrypted`. Ключ — `CURATOR_ENCRYPTION_KEY` в .env.
Дешифровка только на сервере, в момент чтения.

## Альтернативы

- Полагаться на шифрование провайдера БД — отклонено: доступ к СУБД = доступ
  к сырым мыслям.
- Без шифрования, локальное хранение — отклонено: нужен облачный прод.

## Последствия

- Приватность сохранена даже при утечке БД.
- Усложнён поиск/индексация по содержимому (ищем по расшифрованным данным в памяти).
- Смена ключа = перешифровка всех данных (операция редкая, вручную).
