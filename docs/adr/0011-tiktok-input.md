# ADR-0011: TikTok-вход в кураторе — мост к «Зеркалу дня»

Дата: 12.08.2026
Статус: accepted

## Контекст

Пользователь хочет кидать ссылку TikTok прямо в кураторе, не заходя в
отдельное приложение. По решению пользователя (12.08.2026) заметка должна
содержать **полный русский перевод транскрипта видео**.

Пайплайн (скачивание → транскрипция Groq → перевод → мысль) уже живёт в
отдельном сервисе tiktok-watcher и проверен на проде. Дублировать его в
кураторе (ffmpeg + GROQ-ключ + ~400 строк) нецелесообразно.

## Решение

Куратор становится **клиентом** watcher'а (мост, а не встраивание):

- Вкладка «Тикток» заменяет вкладку «Паттерны» (навигация десктоп+мобайл).
  Бэкенд `/api/insights/daily` и `/dreams/patterns` **остаются** — данные
  не удаляются, убирается только вход в раздел.
- `POST /api/tiktok/import` — принимает `{url, note_date}`, валидирует
  `tiktok.com`, пересылает в watcher `POST /api/tiktok`, возвращает `task_id`.
- `GET /api/tiktok?day=` — список задач дня из watcher (для карточек вкладки).
- `GET /api/tiktok/{id}` — статус задачи (поллинг фронта).
- Watcher обрабатывает видео и сам импортирует заметку через `/api/notes/import`
  (перевод → content, мысль → ai_summary, теги `["tiktok", категория]`).
- Конфиг: `TIKTOK_WATCHER_URL` в env куратора. Аутентификация — токен
  пользователя куратора (внутренний вызов watcher — без дополнительных секретов,
  сервис личный, одно-пользовательский).

## Последствия

- **+** Один источник пайплайна (watcher): и поле в кураторе, и iOS Shortcut
  на телефоне дают одинаковый результат.
- **+** Минимум кода в кураторе: два прокси-эндпоинта + вкладка.
- **−** Связка двух сервисов: watcher должен быть жив. Free Render спит —
  первый клип после простоя до 2-3 минут (холодный старт + обработка).
- **−** Заметка появляется асинхронно через 1-3 минуты — поллинг статуса.
- **−** Если watcher недоступен — вкладка показывает ошибку, заметка не создаётся.

## Альтернатива (отклонена)

Встроить пайплайн в куратор целиком (порт download/transcribe/thought,
ffmpeg в Dockerfile, GROQ-ключ в env). Самодостаточно, но дублирует код
и секрет, расходится с единственным источником правды.
