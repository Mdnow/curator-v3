# ADR-0011: TikTok-вход в кураторе — встроенный пайплайн (одно приложение)

Дата: 12.08.2026
Статус: accepted

## Контекст

Пользователь хочет кидать ссылку TikTok прямо в кураторе, не заходя в
отдельное приложение. По решению пользователя (12.08.2026) заметка должна
содержать **полный русский перевод транскрипта видео**.

Сначала была попытка сделать **мост** к tiktok-watcher (куратор — клиент,
watcher обрабатывает видео и импортирует заметку). Решение пользователя:
**одно приложение — куратор, в нём функция watcher. Один код, одна база,
один деплой.** Отдельный сервис не нужен.

## Решение

Пайплайн (скачивание → транскрипция Groq → перевод → сохранение заметки)
**встроен в куратор** (`backend/tiktok_pipeline.py`, порт из tiktok-watcher):

- Вкладка «Тикток» заменяет вкладку «Паттерны» (навигация десктоп+мобайл).
  Бэкенд `/api/insights/daily` и `/dreams/patterns` **остаются** — данные
  не удаляются, убирается только вход в раздел.
- `POST /api/tiktok/import` — принимает `{url, note_date}`, валидирует
  `tiktok.com`, создаёт задачу в `tiktok_tasks`, запускает фоновый
  `process_task(task_id, user_id)`. Возвращает `{id, status}`.
- `GET /api/tiktok?day=` — список задач дня (карточки вкладки).
- `GET /api/tiktok/{id}` — статус задачи (поллинг фронта).
- Воркер: скачивание (tikwm → yt-dlp fallback), ffmpeg → аудио,
  Groq Whisper → транскрипт, Groq llama-3.3-70b → полный русский перевод
  (OpenRouter free — fallback). Заметка: `content` = перевод, `ai_title` —
  описание видео, тег `tiktok`, эмбеддинг фоново.
- Конфиг: `GROQ_API_KEY` + `TMP_DIR` в env куратора. Деплой-инфраструктура:
  `ffmpeg` в Dockerfile, `yt-dlp` в requirements.
- Аутентификация — штатный JWT куратора (`get_current_user`).

## Последствия

- **+** Одно приложение: один код, одна база, один деплой (Render).
- **+** iOS Shortcut на телефоне указывает на куратор `/api/tiktok/import`.
- **−** Пайплайн целиком в кураторе: ffmpeg + GROQ-ключ + ~400 строк кода.
- **−** Заметка появляется асинхронно через 1-3 минуты — поллинг статуса.
- **−** Free Render спит: первый клип после простоя медленнее (холодный старт).

## Альтернатива (отклонена)

Мост к tiktok-watcher (куратор — клиент, watcher импортирует заметку).
Связка двух сервисов и двух деплоев, живые зависимости между ними —
отклонено пользователем: приложение должно быть одно.
