# ADR-0016 — Загрузка файлов в чат Куратора с осмыслением

- **Дата:** 17.08.2026
- **Статус:** accepted

## Контекст

Чат Куратора принимает только текст. Пользователю негде передать
контекст документа (текст, PDF, изображение) для анализа и сохранения —
Куратор не работает как зеркало-ассистент с реальными материалами, а база
личного знания не пополняется внешними документами.

## Решение

В чат Куратора добавляется приём файлов. Файл загружается как обычное
сообщение ветки: извлекается смысл, Куратор отвечает по содержимому, всё
остаётся в истории диалога.

### Схема приёма

- Эндпоинт: `POST /api/chat/upload` (multipart/form-data).
- Поля: `file` (обязательное), `message` (необязательное, текст-дополнение),
  `thread_id` (необязательное; без него создаётся новая ветка).
- Поддерживаемые типы (по расширению и MIME):
  - текст: `.txt`, `.md`, `.markdown`, `.csv`, `.json`, `.log`;
  - документы: `.pdf`;
  - изображения: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.
- Лимит размера файла: **5 МБ** (free-инстанс Render, ограниченная память).
- Лимит извлечённого текста: **20 000 символов** (как у заметки), избыток
  обрезается с пометкой.

### Извлечение смысла

- Текст — декодирование UTF-8 (fallback Windows-1251).
- PDF — извлечение текста через `pypdf` (чистый Python, уже в зависимостях).
- Изображения — описание через vision-модель OpenRouter (free),
  результат — текстовое описание содержимого.
- Если извлечь нечего (скан PDF, битая кодировка, vision недоступен) —
  честная ошибка с пояснением, сообщение не теряется.

### Хранение

- Извлечённое содержимое вставляется в историю ветки как сообщение
  пользователя: `файл: <имя>\n\n<содержимое или описание>`, затем идёт
  обычный ответ Куратора.
- Сам бинарный файл **не хранится** — в базе живёт извлечённый смысл,
  доступный в истории, поиске и бэкапе (принцип: зеркало хранит мысли,
  а не файлы).

## Последствия

- Новый канал наполнения базы: документы и изображения становятся частью
  контекста и истории Куратора.
- Общая логика ответа `/ai/chat` и `/chat/upload` вынесена в один хелпер —
  поведение (заметки-контекст, [NOTE], [SAVE]) одинаковое для обоих путей.
- Vision требует доступности free-моделей OpenRouter; при недоступности
  изображение отклоняется с объяснением, остальные типы работают всегда.
