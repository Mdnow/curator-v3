# ADR-0017: Распределение заметок по проектам из чата — маркер [ASSIGN]

## Контекст

Проекты (ADR-0013) — контейнеры с материалами и своим диалогом. Привязка заметки
к проекту существует в API (`PUT /api/notes/{id}` с `project_id`, notes.py), но
только через ручные кнопки в UI. Чат-куратор про проекты не знает: список
проектов в контекст не попадает, механизма привязки существующих заметок нет.

Пользователь хочет давать чату задание «разложи заметки по проектам» — чтобы
куратор распределял тонко: уверенные привязки применял, сомнительные не трогал,
новые устойчивые темы собирал в новые проекты.

## Решения

1. **Детект просьбы** — набор глаголов-просьб (`разложи`, `распредели`,
   `раскидай`, `привяжи к проектам`, `по проектам»` в сочетании с сортировкой).
   Как у [SAVE:] (ADR-0012): маркер применяется только при явной просьбе,
   иначе вырезается без действия.
2. **Контекст** — список проектов (`[id=5] Книга`) добавляется в системный
   промпт всегда. При интенте распределения добавляется пакет: последние до 50
   заметок **без проекта** (id, дата, заголовок/суммари/категория, первые ~180
   символов) + инструкция.
3. **Маркер действия** — `[ASSIGN:{"<id_заметки>": <id_проекта> | "<имя>", ...}]`
   в конце ответа. Число = существующий проект, строка = имя нового. Применяется
   сразу (без подтверждения), маркер из ответа вырезается, ответ дополняется
   сводкой `assigned` для UI.
4. **Тонкость** — в промпте явно: привязывать только при явном совпадении
   темы; сомневаешься — не трогай; новая устойчивая тема (несколько заметок) —
   новый проект, единичная — оставить.
5. **Объём** — по умолчанию только последние ~50 незакреплённых заметок.
   Остальные — повторным запросом («продолжи»).

## Последствия

- Привязка заметок к проекту возможна и из чата, и из UI; оба пути меняют
  `project_id` у заметки.
- Создание нового проекта из чата — через имя в маркере; дубли имён
  исключаются поиском по точному имени (без учёта регистра).
- AI не может самовольно разложить заметки: без явной просьбы маркер
  игнорируется (защита как у [SAVE:], ADR-0012).
- Сводка применённого возвращается фронту и отображается в чате как
  подтверждение («разложено N заметок»).
