# Для чего создан Curator v3 — EUNOIA OS

## Куратор — когнитивное зеркало

Персональная AI-система Marina. Не «планировщик» и не «напоминалка»: это **когнитивное зеркало**, которое помогает видеть, в чём она реально живёт и думает, — по её же записям.

Основной принцип: самоценность не равна продуктивности (DECOUPLING). Система не давит, не ставит чекбоксы и не навешивает долгов. Она **отражает**: что в мыслях повторяется, что цепляет, какие нити тянутся, какие темы ведут.

## Поток (как работает по замыслу)

```
заметка / сон / мысль из чата  (единственный вход — записи)
   ↓  AI-анализ: категория, summary, тональность, ключевые фразы
   ↓  связи: похожие заметки (embedding), нити (thread_id), паттерны
   ↓  выходы куратора:
        • заметки и избранное        • чат с контекстом (паттерны, сны)
        • сны и их расшифровка       • карта дня (пузыри тем)
        • проявленные цели           • импорт из внешних источников
```

Вход один — записи. Всё остальное (цели, инсайты, карта дня, чат) — **выходы зеркала**, а не долги.

## Состав функций

1. **Заметки** — дневник с AI-разметкой (категория, summary, тональность, ключевые фразы), избранное, нити (thread_id).
2. **Сны** — записи снов + AI-расшифровка (символы, темы, вопрос), паттерны снов.
3. **Чат-куратор** — диалоги с контекстом: сводка тем, последние сны, избранное. AI-промпты дёшево, без лишних запросов.
4. **Карта дня** — когнитивная карта мышления за день: пузыри тем (объём + настрой), фразы дня, нити дня, «фраза дня».
5. **Проявленные цели** — куратор выводит цели из повторяющихся заметок с цитатами-источниками. Без чекбоксов и дедлайнов (заменили раздел «Задачи»).
6. **Импорт из внешних источников** — `/api/notes/import` принимает готовую заметку с AI-полями, без повторного анализа.
7. **Heads Up** — при вводе заметки показывает «куратор видит связь с…» — похожие прошлые заметки (семантический поиск, pgvector).
8. **Бэкап** — полный выгруз со всеми AI-полями.

## Текущий стек

| Слой | Технология |
|---|---|
| Backend | Python + FastAPI, asyncpg |
| БД | PostgreSQL (Neon), pgvector (эмбеддинги заметок) |
| AI | OpenCode Zen (free-модели, ротация) + OpenRouter fallback, embed — OpenRouter |
| Шифрование | все данные пользователя зашифрованы (Fernet) |
| Frontend | vanilla JS + CSS, mobile-first, без эмодзи |
| Деплой | Render (Docker, free, регион франкфурт), деплой через git push |

## Факты

- Прод: `https://curator-v3.onrender.com`
- Пользователь: `mdnow` (Marina), single-user.
- AI: OpenCode Zen (free-модели) первым провайдером, OpenRouter — fallback (embed — OpenRouter).
- Кодировка/стиль: всё на русском, без эмодзи в UI.

## Правила проекта

- Вход всегда один — заметки; цели и инсайты — выход, не долг.
- Без чекбоксов/дат/статусов там, где это давит (продукт-решение 07.08).
- AI-запросы не жечь фоновыми переанализами без необходимости.
- Документы — стандарт: `PURPOSE.md` (зачем), `SESSION_JOURNAL.md` (что сделано),
  `TECHNICAL_JOURNAL.md` (как/проблемы), `GOALS_SPEC.md` (направление),
  `FUTURE_TASKS.md` (план), `docs/adr/` (реестр решений).
